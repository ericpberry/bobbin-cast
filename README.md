# bobbin-cast

The Cast receiver page for Page Reader, a Vedi Apps app for Android that reads documents and web pages
aloud with on-device voices. When Page Reader casts to a TV, the TV loads this page; the phone sends it the
text being read and plays the audio from the phone over the home network. Nothing else is stored or fetched here.

Published from the app's source (commit 5bc7db0); changes made here are overwritten.
